# Archived prototype

This directory preserves the previous implementation, its tests and its supporting
scripts as reference material. Files were moved without rewriting their contents;
their imports, paths and launch instructions describe the original layout.

The maintained implementation is in `../src/kapy/`, with tests in `../tests/`.
The prototype is not included in the current Python distribution, Docker build,
or default lint, type-check and test targets. It has no compatibility entry point
in the current `kapy` package.
